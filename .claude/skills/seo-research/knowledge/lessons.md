# Lessons from /seo-research runs

Append-only, newest first, one dated line per lesson. The orchestrator reads this before every
run and must follow it. Generalise ("Keyword Planner hides Franco terms") rather than recording
niche trivia, which belongs in that niche's report.

- 2026-11-26 — Keyword Planner fails when the signed-in Google Ads login has only Manager (MCC) accounts: the planner says "Please select an account". Check the account type before briefing the worker; a customer account (no spend) is needed.
- 2026-11-26 — For thin B2B niches, skip the alphabet sweep: ~300 autocomplete probes cost ~370K Haiku tokens and 423 tool calls and almost all came back empty. Bare seeds + modifiers + Trends answer "is there demand" for a fraction of the cost.
- 2026-11-26 — Egyptian B2B software terms (`برنامج اتيليه`) can show Trends avg 0 and an empty autocomplete while 5 vendors fight over the SERP. Low demand ≠ no competition; say both.
- 2026-11-26 — English "atelier system/app/software" is polluted by the Atelier video games and Italian "gestionale" software. Use "dress rental software" for English seeds.
- 2026-11-26 — Google's AI answers for Egyptian business how-to queries can cite Gulf sources and quote SAR prices; check the currency and country of AI/PAA answers, it is often the open gap.
- 2026-11-26 — Brief the worker never to navigate a pre-existing tab: the first run reused one of the user's tabs by mistake.
